03 / HISTORY

扫描与回放，分别记录

扫描用截止时点之前的全部K线识别结构。逐日回放在每个交易日重新截断计算，保存首次出现、修订和撤销事件，并核对最后状态。

股票池是当前供应商列表，不包含全部退市成分；历史回放不是无幸存者偏差的收益回测。

04 / MODEL

V4 研究模型

包含处理 → 分型 → 笔 → 线段 → 同级别走势类型递归 → 中枢与背驰 → 多周期确认。

结构证书校验的是本模型声明的规则。候选、待确认、历史不足与已触发分别显示；工作台不连接交易，execution_allowed=false。
