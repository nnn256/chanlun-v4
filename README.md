# 缠论V4版

沪深京A股结构研究工作台：全市场股票池、历史行情、批量报价、包含/分型/笔/线段、走势类型递归、中枢、背驰、六类买卖候选、区间套、小转大、多周期确认、持续扫描、本机提醒和全市场因果回测。

公开备份仓库仅包含程序源码、面板、测试、规则说明和匿名化回测汇总。不上传用户任务数据库、个人路径、行情全量缓存或登录凭据。

## 运行

Python 3.11+，计算核心使用标准库：

```powershell
python run_complete.py demo --output-dir runs/demo
python -m unittest discover -s tests -v
```

桌面EXE不需要系统Python。公开发布资产提供Windows程序；程序仅监听本机，自动提取自己的数据目录，历史任务保留原版本标签。

源码工作台启动需要先保存股票池和行情数据，并提供当前TDX本地服务；缓存路径、来源与哈希必须明确。详细步骤见[V4扫描提醒与全市场回测](V4扫描提醒与全市场回测.md)。

## 面板

- 全市场工作台：股票池、完整历史、图层与结构秩。
- 扫描与提醒：手动/定时扫描、报价覆盖、结构进度、买卖候选、失效边界、事件去重、浏览器桌面提醒。
- 全市场回测：逐股逐根回放、下一根开盘模拟、费用/T+1/标准价格限制、失败/零交易统计和断点续跑。

报价接收时间不是交易所成交时间。首次载入历史候选建立基线；日线候选与day/30m/5m触发分别记录；缺数据或规则未确认时不会伪造触发。

## 回测解释

全市场指当前供应商快照中的沪、深、京A股，并不包括全部历史退市成分。回测按可得已收盘历史推进，不倒用后来确认的端点。每股独立初始资金10万元；跨股平均回报不等于共享资金组合收益。未普遍取得历史公司行为、ST/IPO例外及撮合队列数据，未复权现金模拟属于研究结果，不是已核准的实盘策略收益。

规则口径见[完整算法说明](完整算法V3说明.md)：产品为V4，内部规则profile保留原标识以便追踪。没有宣称证明所有缠论原著争议解释的唯一等价。

## 买卖画图

红色上箭头为买侧，绿色下箭头为卖侧；空心候选、实心模型触发、灰叉失效分别展示。价格端点、结构依据和多周期触发时点独立记录。点击箭头可查看相关中枢、比较/回试段及失效边界，扫描列表可直接定位图中信号。详见[V4买卖画图说明](V4买卖画图说明.md)。

## 4.0.1 买卖点可见性修复

旧版单实例不再静默截获新版启动；没有运行任务时正常关闭旧窗口交接，有任务则明确保留并提示。默认显示带失效状态的历史点，自动定位最近标记，显示买卖数量、当前视图标记数、空秩及真正无信号的原因。产品版本4.0.1，原信号规则及回测统计不变。

## 4.0.2 原始K线与信号落点核验

修正走势分解结束点误作真实价格极值的缺陷，快照与增量回放共用原始区间极值映射；保留分解点、原信号身份及晚于端点的可用时间。旧保存结果保留原字节并在读取时给出校正明细。原始OHLCV默认全部显示、下级细节默认关闭，可逐条核对来源CSV及原接口响应并导出全部原始K线。本级结构完成与多周期触发分列，失效显示具体日期和价格。原全市场回测保留原版本说明，不把旧统计冒充本次新回测。详见[核验说明](V4原始K线与买卖点核验说明.md)。

## 4.1.0 算法基准与显示重建

4.0.x自写结构仅保留作旧结果复现；新图表/扫描使用MIT许可chan.py固定commit核心，原始K线不改。笔级与线段级、原生1p/2s/3a/3b保留差别，逐根事件记录当时可见时间。独立严格极值复核发现的解释分歧不会消失于“换引擎”，相关结构橙色待复核且不确认依赖信号。旧全市场收益回测不能证明新引擎。近期300根清晰蜡烛＋全部历史载入、看图专注和同层结构显示改进。详见[重构说明](V4固定引擎与显示重构说明.md)。

## 4.1.1 今日K线和实时刷新

默认联网显示当前股票真实OHLCV，每15秒更新K线；支持日线/30分/5分，手动刷新立即重新取源。今日未收盘日K显示形成中，确认结构只使用已收盘前缀。区分最新交易日、获取时间与确认结构截止时点；刷新保留缩放，失败明确显示并保留旧数据。详见[V4实时K线说明](V4实时K线说明.md)。本次不改变已披露的结构分歧与旧回测口径。
